# Contributing

Thank you for helping MoteCMS stay small and useful.

1. Open an issue or short proposal for user-visible changes.
2. Keep the core dependency-free and server-rendered.
3. Include tests for behavior changes in `tests/run.php`.
4. Run PHP linting and `php tests/run.php` before submitting.
5. Document byte-cost tradeoffs for features that affect public payloads.

Avoid adding frameworks, build tooling, external assets or public JavaScript unless there is a clear, reviewed reason.
